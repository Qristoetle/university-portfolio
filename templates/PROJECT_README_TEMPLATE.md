# 项目名称

用一句话说明项目解决的问题。

## 背景

填写课程或比赛、完成时间、团队协作情况及本人承担的具体工作，只记录可以确认的信息。

## 功能与成果

列出已实现功能。实验指标写明数据、时间范围和评价口径，并附相关结果文件。

## 技术与结构

说明主要技术和目录职责。

## 展示

附项目截图、演示或答辩资料的相对链接；视频较大时使用单独发布的附件链接。

## 运行

写明环境要求、依赖安装、示例配置、启动步骤及可打开的地址。

## 验证

记录可运行的测试或检查步骤，并区分已验证功能和需要额外账号、数据或设备的功能。

## 数据与归属

说明样例数据与完整数据的区别、第三方依赖及代码和素材的归属。

## 复盘

记录遇到的问题、解决方法及仍存在的局限。
